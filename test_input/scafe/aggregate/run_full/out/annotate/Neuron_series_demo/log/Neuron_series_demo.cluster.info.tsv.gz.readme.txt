=================
File descriptions
=================
TSS cluster centric annotation, one-row-per TSS cluster, with infomation of its associated genes


===================
Column descriptions
===================

column              description
------              -----------
clusterID           [unique ID] Identifier of the TSS cluster.
clusterName         [string] Name of the cluster, in format of [p|e][rank]@[geneNameX],[p|e][rank]@[geneNameY]
type                [gene_tss or unanno_tss] the TSS cluster is annotated as gene tss or not
score               [integer] score in the input bed
geneNum             [string] number of gene associated with the TSS cluster
trnscptIDStr        [string] ID of transcripts associated with the TSS cluster, ";" delimited.
geneIDStr           [string] Identifier of gene associated with the TSS cluster, ";" delimited. Mainly inherited from the "gene ID" field in GENCODE or FANTOM CAT, plus "addon" genes from groups of unannotated TSS clusters [ADDG#########].
geneNameStr         [string] Name of gene associated with the TSS cluster, ";" delimited. Mainly inherited from the "gene name" field in GENCODE, , plus "addon" genes from unannotated TSS clusters [ADDG#########].
geneClassStr        [string] Class of gene associated with the TSS cluster, ";" delimited. if anno was from genecode, it refers to the biotype of the genes from genecode. if anno was from FANTOM CAT, it refers to the gene classes of the genes in FANTOM CAT.
codingClassStr      [string] Assigned based on predefined coding status of geneClass
proximity           [proxmial or distal] proximity or distal to genes tss
regionType          [end5 exon intron or intergenic] within or in the proximity of the end5, exon or intron, or else intergenic
regionOritentation  [ns ss or as] oritentation relative to the region in regionType, sense strand, antisense strand, or non-stranded
regionGeneID        [unique ID] ID of the gene which contributes to the annotation of the regionType
class               [coding, noncoding, distal and other] cluster of coding gene tss, cluster of noncoding genes tss or cluster that is distant from gene tss, or others (including cluster that is close to gene tss but not on the same strand as the gene of mixed of multiple genetypes)
CREID               [unique ID] ID of the CRE the cluster belongs to
prob                [float] False discovery rate of cluster on background filtering
