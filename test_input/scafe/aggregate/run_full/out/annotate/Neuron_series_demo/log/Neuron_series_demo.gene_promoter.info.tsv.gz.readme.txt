=================
File descriptions
=================
list of annotated and unannotated gene promoters as pairs of CREID and geneID


===================
Column descriptions
===================

column                 description
------                 -----------
CREID                  [unique ID] Identifier of the CRE.
geneID                 [unique ID] ID of the gene which the CRE is defined as its alternative promoter
geneName               [string] gene symbol
total_exp_frac         [fraction] the fraction of expression amount (UMI in single cell/read in bulk) of this CRE in the total expression amount of annotated alternative promoters
gene_strand_read_frac  [fraction] the fraction of expression amount (UMI in single cell/read in bulk) of this CRE on the gene strand in the total expression amount of both strands
sumClusterRead         [integer] sum of read within its member cluster
status                 [annotated or unannotated] annotated, CRE that is assigned to annotated transcripts (in reference annotation) of the gene, or unannotated otherwise
loc                    [string] locus, in format of chromosome:start-end
